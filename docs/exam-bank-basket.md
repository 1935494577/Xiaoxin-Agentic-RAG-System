# 题库闭环 vs 知识库检索

> 产品对照：[学科网智能组卷](https://zujuan.xkw.com/) 的「题卡 + 试题篮 + 一键组卷」形态。  
> **不做**商业题库抓取；只复用交互结构，数据全部来自本系统入库。

## 两条路径（可并存）

| | **题库子系统（当前主路径）** | **知识库 RAG（远期增强）** |
|--|--|--|
| 入库 | Admin 试卷入库 → 拆题 → `questions` + `source_papers` | Chat 文档入库 → 向量块 |
| 选题 | 按 **地区·学科·年级** 独立题库 + 章节/知识点/难度/年份 | 语义检索相似题干 |
| 组卷 | 一键抽题入篮 / 试题篮加减 / 定稿导出 | 检索结果「加入试题篮」后同上 |
| 溯源 | `source_paper_id` → 原卷标题/原文 | chunk 来源文档 |

**推荐落地顺序**：先把题库闭环做稳（地区建库 → 入库元数据 → 约束抽题 → 试题篮 → 导出），再把 RAG 检索结果接到同一「试题篮」状态上。

## 当前已闭环逻辑

1. **建库**：必须选地区；库名自动 `地区·学科·年级`；同作用域不可重复。
2. **入库**：题目 `region/subject/grade` 强制跟随题库；写入 `year/chapter/knowledge_tags`。
3. **组卷**：在选定地区库内，按题型/难度/章节/知识点/年份抽题。
4. **试题篮**：抽题结果以题卡展示；可加减；「去组卷并导出」定稿。
5. **原卷**：题卡可点「查看原题试卷」（`source_papers`）。

## UX 对应

- 试题篮 ≈ 右侧篮  
- 一键抽题 ≈ 智能组卷按模板生成  
- 卷面放大 ≈ 正式卷预览
