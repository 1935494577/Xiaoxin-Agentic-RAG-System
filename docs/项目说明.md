## 1. 产品是什么

**Jnao（劲脑）Enterprise RAG** 是面向企业内部制度与长文档的检索增强对话平台，并扩展 **题库组卷** 子系统（与 Chat 数据隔离）：

| 角色 | 主要入口 | 能做什么 |
|------|----------|----------|
| 一线员工 | Jnao Chat（8502） | 问知识库、带引文回答；可选任务模式走工具 |
| 管理员 / 运营 | `/admin` | 入库、**题库组卷**、模型/提示词/场景、反馈分诊、评测、Token、IM 渠道 |
| 外部客户端 | Main API（8010） | `/chat`、`/chat/stream`、`/api/exam/*`、入库与配置 API |
| IM 机器人 | Harness Gateway（8011） | 飞书等渠道 Worker（需 harness 启动） |

品牌与视觉约束见根目录 [`PRODUCT.md`](../PRODUCT.md)、[`DESIGN.md`](../DESIGN.md)。

## 2. 运行拓扑

```text
┌─────────────────┐     ┌──────────────────────┐     ┌─────────────────┐
│  Frontend 8502  │────▶│  Main API 8010       │     │ Gateway 8011    │
│  Chat + Admin   │     │  RAG / Chat / Admin  │◀───▶│  IM / harness   │
└─────────────────┘     │  Token SQLite 等     │     └─────────────────┘
                        └──────────────────────┘
```

| 端口 | 进程 | 启动方式 |
|------|------|----------|
| **8010** | FastAPI Main（`api.main`） | `run-dev.ps1` / `run-dev-harness.ps1` |
| **8011** | Harness Gateway（渠道、部分 Agent 能力） | `run-dev-harness.ps1` |
| **8502** | Vite React SPA | 同上 |

- 日常 Web Chat / 知识库：**8010 + 8502** 即可。  
- IM 与任务侧 harness：**再加 8011**（`run-dev-harness.ps1`）。  
- DeerFlow 编排约束见 [`deerflow-integration.md`](./deerflow-integration.md)。

## 4. 当前能力（按链路）

### 4.1 文档 → 索引

- 解析清洗 → 父子分块 → 向量（Milvus Lite / numpy 回退）+ 父块 BM25  
- 入库去重（content_hash / simhash）  
- 可选 Elasticsearch 父索引、ModelScope 本地模型缓存  

### 4.2 检索

- Query Understanding：口语清洗 → alias → 领域词表 → embedding 近邻 → 条件 LLM rewrite → 多路 RRF  
- 向量 + BM25 混合、重排、检索缓存（Redis 或进程 TTL）  
- 置信度分层（confident / gray / weak）；**strict KB 未通过则清空 ctx**，避免寒暄被脏片段带偏  
- 专题：[`query-understanding.md`](./query-understanding.md)

### 4.3 对话

| 能力 | 现状 |
|------|------|
| 助手模式 | `knowledge` / `task` / `auto`；**默认知识模式**（Web / IM / UI 配置兜底） |
| 寒暄短路 | 「你好 / 谢谢」等：**不检索、不调 LLM**，固定短回复 |
| 流式 | SSE（`/chat/stream`），ExecutionTimeline 展示检索→工具→生成 |
| 多架构 | Classic / Graph / Agentic 路由；KB-only 默认可走 direct 推理 |
| 多轮 | L1–L4 上下文；见 [`conversation-context.md`](./conversation-context.md) |
| 工具 | 任务模式可走 tool loop；`kb_search`、关系图等 |
| 场景预设 | Admin 一键：一线 KB / 内测全功能 / LAN API 等 |

专题：[`rag_architecture_router.md`](./rag_architecture_router.md)

### 4.4 Token 计量（独立 SQLite）

- **不复用** DeerFlow RunStore；库文件默认 `enterprise_rag/data/token_usage.db`  
- 调用点：`answer` / `tool_loop` / `verifier`  
- API：会话徽章 `GET /api/threads/{id}/token-usage`；全局 `GET /api/token-usage/summary`（含 **按用户提问聚合 turns**）  
- Admin「Token 用量」：总量、按模型、按提问汇总、**今日一览**（Token + 反馈 👍👎 + 检索未命中）  
- 轻量运营：`GET /api/ops/digest?since_days=1`

### 4.5 题库 / 组卷（独立子系统）

- 代码：`enterprise_rag/src/exam_bank/`；库：`exam_bank.db`；API：`/api/exam/*`  
- **与 Chat / Milvus 隔离**：组卷走 SQL 约束，不写主向量索引  
- 场景：`exam_assemble`（组卷）、`exam_lesson` / `exam_ingest`（预留）  
- Admin：`/admin/exam-bank` **首页入口**（入库向导 / 导出单页 / 管理）；入库五步可退回；导出按科目题型填道数与难度后生成；答案可跳过  
- 资产 ACL：`platform_acl`（`private` / `tenant_shared` / `platform` + `owner_user_id`）；方案见 [`data-platform.md`](./data-platform.md)  
- 向导：[`exam-bank-wizard.md`](./exam-bank-wizard.md)；入库：[`exam-bank-ingest.md`](./exam-bank-ingest.md)  
- 路由说明：[`exam-bank-routing.md`](./exam-bank-routing.md)  
- 契约：[`exam-bank-api.md`](./exam-bank-api.md)、[`exam-bank-assemble-v2.md`](./exam-bank-assemble-v2.md)、[`exam-bank-issues.md`](./exam-bank-issues.md)

### 4.6 反馈闭环

```text
Chat 👍👎 → Collect → Triage（规则/LLM）→ Inbox 审核 → Actuator（白名单）
                                      → golden / alias / 配置补丁 / 重入库工单
                                      → 评测报告（RAGAS 或 naive）
```

- Feedback 故障 **不得** 打挂 Chat 热路径  
- Admin：反馈收件箱、评测报告、链路 Trace  

### 4.7 安全与权限

- 可选 `RAG_API_SECRET` / `RAG_ADMIN_API_SECRET`、CORS、可信 Host  
- Admin 角色：viewer / operator / admin  
- 部门功能门控 + 文档可见范围 ACL  
- 租户预留：`X-Tenant-ID`（默认 `internal`）、`/api/v1` 别名  
- 部署清单：[`deploy_security.md`](./deploy_security.md)、[`production_deploy.md`](./production_deploy.md)

### 4.8 前端 Admin 导航（现状）

日常运营：入库、**题库组卷**、业务场景、教程  
质量闭环：用户反馈、评测报告、Trace、Token 用量  
系统配置：对话设置、提示词、模型、工具、向量库、IM 渠道、账号

## 6. 本地怎么跑（最短路径）

```powershell
# 仓库根目录
copy .env.example .env          # 填 OPENAI_* 等

.\scripts\run-dev-harness.ps1   # 8010 + 8011 + 8502
```
