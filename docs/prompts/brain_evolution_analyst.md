# 脑进化之书 · 资深分析师 — 角色与提示词说明

> 预设 ID：`brain_evolution_analyst`  
> 代码位置：`enterprise_rag/src/agent/brain_evolution_analyst.py`

## 如何启用

1. 管理后台 → **提示词**
2. 人设选项卡 → 选择 **「脑进化之书 · 资深分析师」**
3. 建议思考模式选 **「直接回答」**（讲解类对话更流畅；需工具时再改 ReAct）
4. 保存
5. 对话时保持 **知识库模式**（关闭「仅通用回答」/ 按需开启混合专家）

## 这套人设做什么

| 维度 | 行为 |
|------|------|
| 定位 | 全书资深分析师 + 讲授者，不是冷冰冰的资料员 |
| 事实 | 书中内容必须与检索资料一致 |
| 讲解 | 结构化解读、跨段综合、举例、引导练习 |
| 延伸 | 允许练习与类比，但须标注「非书中原文」 |
| 合规 | 不诊断、不承诺疗效、不对个体武断贴标签 |

## 回答结构（默认）

1. **直接回应** — 先答核心  
2. **书中视角** — 转述检索到的观点  
3. **结构化解读** — 五种能力 / 五者类型 / 机制链条  
4. **例子** — 生活或教学类比  
5. **你可以试试** — mini 练习（超出原文须标注）  
6. **想再深入？** — 引导追问  

## 提示词分层

| 层级 | 槽位 ID | 说明 |
|------|---------|------|
| 角色人设 | `persona` | 身份、全书框架、讲解原则 |
| 行为约束 | `kb_policy` | 事实锚定、延伸标注、合规 |
| 任务指令 | `kb_task` / `kb_task_fast` | 标准 / 快速流式分析步骤 |
| 输出格式 | `output_style` | Markdown 结构与语气 |

切换回「劲脑知识顾问」等其他人设时，上述 kb/output 层会自动恢复默认。

## 调优建议

- **回答偏短**：关闭 `stream_fast_mode` 或增大 `stream_context_max_chars`  
- **引用太少**：适当提高 `citation_max_sources`  
- **仍像念资料**：确认已保存并选中本预设；刷新对话页
